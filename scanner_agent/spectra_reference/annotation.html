SPECTRA S2.2c - interactive reference annotation

Experimental. Annotate the intended outer PRINTED FRAME, not physical edges, artwork, text boxes or shadows. Neither saving nor confirming a reference establishes independent validation or calibrated accuracy.

1. Select a side. 2. Zoom into the printed border. 3. Drag the green line or its handles. 4. Verify alignment along the side. 5. Explicitly confirm the reviewed side. 6. Export the reference.

Visual editor

Click a green line or orange endpoint to select it. Drag to edit; release to commit. Drag empty space, use the Pan tool, or hold Space to pan. Mouse wheel/trackpad zooms at the pointer. Hold Shift before dragging for fine motion. Arrow keys nudge the selection by 1 original px (Shift/fine: 0.1 px); Escape deselects or cancels. Ctrl+Z / Ctrl+Y undo/redo.

Pointer coordinates appear here.

Cyan: physical boundary. Magenta: automatic candidates. Green: reference (dashed until confirmed). White halo: active side. Orange handles: independent endpoints; white-filled handle is selected. White dashed: drag/numeric preview.

Side review

Candidate selection and all geometry edits remain unconfirmed. Confirm only after reviewing the intended border along the whole usable span. Showing or selecting a detector candidate can bias the reference; confirmation is not proof of independent validation.

Advanced numerical offsets and evaluation span

Offsets are measured at the evaluation-span endpoints, which can differ from freely dragged handle positions. Changing only the span preserves the line. Values are never rounded before export. Invalid drafts remain available when switching sides and block export.






Unconfirmed and ambiguous sides may be exported, but cannot be ranked as a complete reference. Use the existing Python save/compare commands. Previously prepared HTML files are immutable snapshots: regenerate an interface to use this editor.
